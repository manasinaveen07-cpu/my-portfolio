# Manasi N — Portfolio

A React + Vite developer portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Customize before publishing

- Replace `#` project GitHub links in `src/main.jsx` with the actual repository URLs.
- Add an email/contact link if desired.
- Add a profile photo if desired.
- Update project descriptions as your projects evolve.

## Build

```bash
npm run build
```
